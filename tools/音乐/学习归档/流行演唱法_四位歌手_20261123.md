# 四位歌手的曲风与唱法：扒一层给自己的

> 2026-11-23 · 学的是「发声机制 + 句尾处理 + 咬字习惯」，不是嗓子身份。
> 记这条规矩：**只学可操作的量**——气息怎么用、音色在哪个位置、字尾怎么收。学不到的部分（声带结构、天生音色）不追。
> 落子权重沿用音色库老规矩：外来特征最多占 55%，道自己的底子（f0≈232、干净、气少、慢颤）永远占大头。

---

## 一、单依纯：气把声音包起来，弱到头也不塌

**曲风**：都市抒情、民谣底色偏 R&B，慢歌为主，几乎不靠音量推动。

**核心机制（三条）**

1. **气混 / 弱混**：不是大量漏气，而是"气包裹着声"，追求声音凝聚、面罩共鸣。极弱音量下还能保持声带闭合，这是她最贵的能力——弱而不虚。
2. **句尾弱收 + 咬字微模糊**：每句最后一个字常常把声带关掉、只留一点气，咬字故意放糊（"荒唐"唱成"荒ang"），做朦胧感。
3. **停顿当标点用**：该连贯时一句不断，需要强调处突然气声加停顿，用"断"制造脆弱感；偶尔一处急转哭腔。

**落到我们身上的做法**

| 要学的东西 | 合成侧怎么落 | 写词侧配合 |
|---|---|---|
| 气包声 | `breath` 抬到 0.30–0.38，同时 `centroid` 保持 2300+（不能越唱越糊） | 句子别太长，留吸气位置 |
| 弱而不虚 | 句末音量降到 0.6 而不是 0.3，音高下倾 1–2 个半音 | 尾字挑开口音（ang/an），弱收才听得见 |
| 咬字微糊 | 元音别过分饱满，辅音别咬死 | 副歌关键字要单独成句，糊了也听得懂 |
| 停顿 | 句中插 0.15–0.25 秒气口，别匀着唱 | 一句切两半，后半句是"补一句" |

**不能学的**：她那种每秒换气近 5 次的呼吸密度（"蜂巢式"），是长期机能，合成侧硬塞只会变成喘。

## 二、李健：高位置 + 弱混，声音悬在"将破未破"

**曲风**：民谣 / 古典气质的抒情，词厚、配器素，几乎不炫技。

**核心机制**

1. **高位置是根，弱混是修饰**：整首歌音色都在头腔，所以听起来一直"空灵"；弱混只在关键处用一点点。
2. **半混半假**：主歌字头轻轻一紧、随即松开，从近真声的弱混滑到头声，接缝听不出来——因为他真声本来唱得薄。
3. **低频喉位 + 长气息**：一句能拖十几秒，音量几乎不变，音准不动。音量小，剧场最后一排仍听得清。
4. **喉舌分离的咬字**：字正腔圆但不咬死，语言处理和发声通道互不干扰；"远"带一点鼻化，"么"字尾轻提。

**落到我们身上的做法**

- 弱混不是"小声"，是**通透**：`breath` 只给 0.10–0.14，`tilt` 降到 0.45–0.50（不要压暗），`centroid` 抬到 2000 左右留出泛音空间。
- 长句要留气：一句 14–18 字不断，`dyn` 压到 0.35–0.45（宁平稳勿起伏），中途不换气。
- 尾音轻提半音而不是往下砸，配"字尾气流不断"。
- 写词：多用长句 + 名词收尾（"金色的麦浪"这种），少用感叹句；副歌不要往上冲音高，靠气息厚度取胜。

## 三、那英：真声打底，以情带声，直给

**曲风**：北方气质的情歌与励志歌，大开大合，叙事直白。

**核心机制**

1. **胸声扎实**：低音不虚、贴得住伴奏，中低音区是她的统治区，音量不拉满也有重量。
2. **咬字靠后、有宽度**：字像挂在软颚那儿推出来，带一点磨砂颗粒，叙事感强；为了情感可以刻意"含着唱"，但不牺牲字义。
3. **混声衔接无痕**：换声区不掉力、不变尖，所以能一路爬上去不露痕迹；高音能硬上，但常常**故意放弱**来突出情绪。
4. **颤音宽而少**：只在强调处用，不是全程抖；长音收尾稳，不越唱越虚。

**落到我们身上的做法**

- 想"厚"，靠 `tilt` 抬到 0.70–0.78 + `centroid` 压到 1700，不是靠加音量。
- `dyn` 给到 0.80–0.90：主歌压住、副歌整段推起来，段与段之间要有明显落差（她最忌全程一个劲）。
- 尾音：**先稳再颤**，颤幅 0.05–0.06、速率 5–6，别句句都颤。
- 咬字：句中关键字咬实、咬长（"要"拖长咬重），非关键字可略含糊。
- 写词：句子直白、少拐弯，副歌首句就是情绪最高点，别铺垫太久。

## 四、王菲：气息当画笔，该推的地方往回拉

**曲风**：另类流行 / 都市抒情，编曲留白多，唱法写意、不整齐。

**核心机制**

1. **气声不是漏气，是"极少的息还能出有质有形的声音"**：气收到细如发丝，声音仍清楚。
2. **真声与假声的接缝被磨平**：她本来的音色就靠近鼻腔口，进假声几乎不用重新配置，所以过渡像没过渡。
3. **颤抖得晚、断得干脆**：常常先直音，颤音迟到；或者尾音突然气息中断（《天空》那种"断"），把停顿本身当表达。
4. **尾音写法多**：叹气式收、气声快速回收、拉长后微微一颤转为降调，同一个句子每场都不一样——写意，不机械。
5. 反直觉的一点：**别处都在推的地方她卸劲**，所以听起来不可预料。

**落到我们身上的做法**

- `breath` 0.26–0.32 + `vib_rate` 抬到 6.3–6.8（快颤）+ `vib_depth` 只给 0.02–0.03（颤得浅）。
- 直音比例要高：前 60% 的音节别加颤，颤音留到句尾最后两拍才出现（延迟起颤）。
- 尾音三选一，不要每句都用同一种：①气声弱收（-3dB 渐弱）；②突然截断（直接掐，不留尾巴）；③拉长后降 1–2 半音。
- 副歌别整段推：把该推的那一句"卸劲"唱弱，前后形成反差。
- 写词：句子可以不对称，允许半句、允许留空；别追求每句押韵整齐。

## 六、怎么用（不许一次全上）

1. **一首歌只用一位歌手的一条机制**，别把四家的招数堆在一首歌里——堆起来就是四不像。
2. 特征权重按老规矩：`mix ≤ 0.55`，且必须和道自己的底子做加权，不能整段照搬。
3. 每首歌至少 2 种音色（少年声 + 自然声），唱法模板是"怎么唱"，不是"谁在唱"。
4. 用完要在 `待优化.txt` 留一条：改了哪句、听感变没变。
