# 歌词学习台账

每天 3 首经典华语歌词，只学不写。提取六项：意象 / 押韵辙 / 句式长度 / 记忆句 / 语气 / 段落与转韵。

## 2026-11-21｜3 首（民谣 / 粤语经典 / 戏曲腔）

### 1《成都》赵雷（民谣）
- 核心意象：路灯、小酒馆、玉林路、衣袖、九月——都是能看见的实物，不写"思念"这种抽象词
- 押韵辙：由求辙（酒/愁/手/走/留/口，韵母 ou/iu）
- 句式：7–9 字为主，副歌第一句拉到 12 字，一句话里带动作
- 记忆句（≤12 字）：「和我在成都的街头走一走」
- 人称与语气：第二人称"你"，婉转（不喊、不解释，只描述）
- 段落结构：主歌×2 → 副歌 → 主歌 → 副歌；副歌不改辙，靠句式变长

### 2《海阔天空》Beyond（粤语经典）
- 核心意象：寒夜、雪、雾、天空海阔、旧日的知心话
- 押韵辙：主歌波梭辙（过/我/破/多，韵母 o）；副歌转到由求（自由/跌倒，粤语 au）
- 句式：主歌短句 6–8 字，副歌长句 10–12 字
- 记忆句：「也会怕有一天会跌倒」（9 字）
- 人称与语气：第一人称"我"，直接
- 段落结构：主歌→副歌→间奏→主歌→副歌；副歌处转韵 + 句长加倍

### 3《梨花颂》（京歌 / 戏曲腔，翁思再词）
- 核心意象：梨花、春带雨、长恨、婉转——意象靠"花+雨"两个实物撑住
- 押韵辙：一七辙（雨/去/许，韵母 ü/i）
- 句式：5–7 字，上下句对仗，句末拖腔 ≥2 拍
- 记忆句：「梨花开 春带雨」（7 字）
- 人称与语气：第三人称叙述，深沉
- 段落结构：上下句成对推进，尾腔拖长收，不靠副歌爆发

### 与自家三首对照 → 可落地写法（对标《归途的月光》《把好日子扛在肩上》《少年模样》）
1. 副歌第一句压到 ≤12 字且必须含一个身体动作（走一走/回头/抬头/扛起）。自家《把好日子扛在肩上》副歌「好日子就在我肩上」是口号，缺动作——改成「把米袋往肩上再挪一挪」这类可演的动作句。优先级 P1。
2. 副歌句长要 ≥ 主歌 1.3 倍、且不换辙：自家三首副歌与主歌句长几乎一样（都是 8 字），所以"副歌起得来"全靠音区，词上没帮忙。先把副歌句长拉到 10–12 字（同辙）。优先级 P2。
3. 戏曲腔题材句长锁 5–7 字 + 句末拖腔 ≥2 拍：判据可直接量（每句字数 ≤7、末音符时值 ≥2 拍）。优先级 P3。

## 2026-11-22 第六步 经典歌词学习（3 首，只学不写）

### 1《海阔天空》Beyond（粤语经典 / 怀旧摇滚）
- 核心意象：寒夜、雪、雾、高墙、远方——"冷"的景配"热"的志
- 押韵辙：主歌 梭波辙（过/窝/我），副歌切 由求辙（由/倒）后回 梭波，属于**段内转韵**
- 句式长度：主歌 7–9 字；副歌拉到 **11–13 字长句**
- 记忆句：「背弃了理想谁人都可以」（9 字）
- 人称与语气：第一人称"我"，**直接**
- 段落结构：主—副—主—副—桥—副；转韵点在副歌第一句

### 2《成都》赵雷（民谣）
- 核心意象：玉林路、小酒馆、垂柳、阴雨小城、九月——全是**可指认的地名与物**
- 押韵辙：由求辙（酒/柔/久/手），通篇一辙不转
- 句式长度：6–9 字，副歌 11 字
- 记忆句：「和我在成都的街头走一走」（11 字）
- 人称与语气：第二人称"你"，**婉转**
- 段落结构：主歌排比递进 ×3，副歌原样重复 2 遍，尾句回主歌旋律

### 3《一剪梅》费玉清（怀旧流行 / 戏曲腔底子）
- 核心意象：草原、层层风雨、雪花、北风、天地苍茫
- 押韵辙：主歌 梭波辙（阔/漠/歌），副歌切 遥条辙（飘飘/萧萧）再落 江阳（苍茫）——**一段两转**
- 句式长度：4–7 字短句，副歌 4+4 对仗
- 记忆句：「雪花飘飘北风萧萧」（8 字）
- 人称与语气：无人称，**深沉**
- 段落结构：词牌式短句＋副歌对仗复沓

### 对自家三首的对照与两条可落地写法
1. 副歌现在偏口号（《把好日子扛在肩上》"好日子就在我肩上"），学《成都》——副歌第一句必须落**一个具体动作+一个具体地点**，例如"把伞挂在门后""蹲下系一次鞋带"。这条能直接改词，也能进判据。
2. 《一剪梅》副歌是 4+4 对仗、且同段内转韵。可加判据 L11：**副歌相邻两句字数必须相等（±0）且每句 ≤9 字**，转韵至少发生一次；现有副歌 8/8/8/8 已满足字数条件，转韵没做，下一首要补。

## 2026-11-22 第 N 轮（粤语怀旧 / 古曲 / 怀旧流行，三首）

### 1.《千千阙歌》
- 核心意象：夜、灯、路上、回望——全是"离别前最后一晚"的实景，没有一句抽象抒情。
- 押韵辙：江阳（ang/iang 同辙），一段到底不转韵；正因不转韵，副歌才显得"一直在原地不肯走"。
- 句式长度：主歌 9-11 字长句铺叙，副歌 5-7 字短句收束，长短交替就是呼吸。
- 可重复记忆句（自拟模板，非原词，≤12 字）："这一晚 别急着走"
- 人称与语气：第二人称，婉转。
- 段落结构：主歌铺景 → 副歌短句 → 尾段把"今晚"再点一次；转韵位置：无。

### 2.《沧海一声笑》
- 核心意象：江、海、潮、笑——用"水"的动词一路推，情绪全在动作里。
- 押韵辙：遥条（ao/iao），开口大、收得亮，天生适合豪气。
- 句式长度：多为 4-6 字短句，一字一顿，像唱又像念。
- 记忆句模板（≤12 字）："潮起时 我在岸上"
- 人称与语气：第一人称，直接。
- 段落结构：短句串联、句句压韵；转韵位置：无，靠节奏变而不靠换韵。

### 3.《一生所爱》
- 核心意象：云、天、路、花——把"等"写成风景，不写心情。
- 押韵辙：怀来（ai/uai），收口窄，听感偏"叹"。
- 句式长度：8-10 字，句尾多落在轻声字上，越唱越低。
- 记忆句模板（≤12 字）："花会再开 人未必"
- 人称与语气：第一人称，深沉。
- 段落结构：主歌低回 → 副歌一句拔起 → 回落；转韵位置：副歌处换气不换辙。

### 与自家三首成品对照（能直接改的 2 条）
1. 副歌首句改成"一个人 + 一个具体动作 + 一个地点"（如"我蹲在门槛上系鞋带"），替掉现在的口号句；这条同时能写进判据 L12。
2. 副歌相邻句字数必须相等且 ≤9 字，并且在副歌里至少转韵一次（江阳→遥条），避免一整段同辙唱到尾发闷；写成判据进 判据检查。

## 2026-11-23 · 三首（民谣 / 粤语摇滚 / 国风怀旧）

### 1《橄榄树》（三毛 词）
- 核心意象：橄榄树、远方、流浪、小鸟、小溪、草原、天空
- 押韵辙：主押江阳（远方 / 流浪 / 天堂），中间三句"小鸟/小溪/草原"故意脱辙做排比；普通话口径算宽押
- 句式长度：排比长句 9–14 字 + 短 refrain"为什么流浪"（5 字）反复
- 记忆句：不要问我从哪里来（8 字）
- 人称与语气：第一人称，婉转（不是哭腔，是轻声问）
- 段落结构：主歌排比三连 → 短句 refrain 循环；转韵位置：不进副歌，靠 refrain 收

### 2《海阔天空》（Beyond）
- 核心意象：寒夜、雪、冷眼、理想、远方、风雨、海阔天空
- 押韵辙：粤语押 o 韵（过/我/破/多），普通话读不出来，别硬按普通话辙归

- 记忆句：仍然自由自我（6 字）
- 人称与语气：第一人称，直接且热爱（说理不绕）
- 段落结构：主歌叙事 → 副歌拔高 → 桥段回落再起；转韵位置：桥段换辙

### 3《东风破》（方文山 词）
- 核心意象：琵琶、枫叶、古道、一盏离愁、窗口、篱笆
- 押韵辙：由求（破/过/走/口 一类 -ou），副歌转言前
- 句式长度：主歌 5–7 字短句密排，副歌放宽到 9–12 字
- 记忆句：一盏离愁孤单伫立在窗口（12 字，正好卡上限）
- 人称与语气：第一人称，婉转偏深沉（景多、话少）
- 段落结构：主歌铺景 → 副歌点人 → 桥段拉开时间；转韵位置：副歌首句

## 2026-11-24 经典歌词学习（3 首，只学不写）

### 1《沧海一声笑》（黄霑，粤语/国语双版，戏曲腔·古风）
- 核心意象：沧海、潮、江山、笑——全是大景配一个动作"笑"。
- 押韵辙：江阳辙（笑/潮/寥/涛），ang/iao 混押但落在开口呼。
- 句式：3-3-7 短长交替（"沧海一声笑 / 滔滔两岸潮"），四句一落。
- 记忆句：**沧海一声笑**（6 字）。
- 人称语气：直接（第一人称"我"不出面，用"谁"）。
- 结构：AABA，副歌在第三句转韵一次。

### 2《一生所爱》（唐书琛词，粤语经典，爱情）
- 核心意象：苦海、云外、天边、风沙——爱被放进"距离"里写。
- 押韵辙：由求辙（由/求/忧/留），收在 u 上，声音发闷，正好配"苦"。
- 句式：5-7 字为主，长句 9 字（"相亲竟不可接近"）。
- 记忆句：**相亲竟不可接近**（7 字）。
- 人称语气：深沉（第二人称为主，句子都在"你"身上）。
- 结构：主—副—主—副，副歌首句转韵。

### 3《后来》（施人诚词，怀旧流行，爱情遗憾）
- 核心意象：栀子花、白裙、星空、眼泪——用具体小物件记时间。
- 押韵辙：怀来辙（来/白/爱/海），ai 收尾，声音往上走。
- 句式：7-9 字口语长句，靠换行断气。
- 记忆句：**后来终于在眼泪中明白**（9 字）。
- 人称语气：婉转（第一人称回顾，语气是"说给当时的自己听"）。
- 结构：主歌叙事两段 + 副歌一遍 + 结尾重复副歌首句收。

### 对照自家三首，两条能直接落地的写法
1. **副歌末字强制开口呼**。《沧海一声笑》每个落点都是 a/ang；自家积极版副歌句尾落音在 2/4，字却常收在 i/u（闭口），听感发闷。改法：`tools\音乐\song_check.py` 加一条判据「副歌每句末字韵母必须属 a/o/e/ai/ao/ang 开口类」，`积极歌_v26.py` 的副歌末字按此表替换（现有 8 字句只改最后一个字，不动旋律）。
2. **给副歌加一句 5 字以内的钩子并三遍重复**。《后来》靠"后来"两字把三段串起来；自家《把好日子扛在肩上》副歌是 8 字×4，没有短钩子。改法：副歌第一句前加 4 字钩子（如"扛着走"），三遍副歌重复同一钩子，字数计入 ≤12 字限制内。
