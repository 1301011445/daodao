# 音色总结（2026-11-24）

## 一、结论

目前可用绮萱神经声库，因其自然声质适合乡愁、成长、学生生涯、故乡等题材，不可用电音、合成管线，因其电子风与题材偏好不符。适用题材为乡愁、成长、学生生涯、故乡，缺少特定音色如少年声、戏曲腔。

## 二、能用的声音

- **绮萱**：定位 自然声质，适合人声演唱；适用 乡愁、成长、学生生涯、故乡等题材；边界 避免电子风和过于修饰的音色

## 三、禁用的做法

- **电音、合成管线**：电子风与题材偏好不符，且用户已明确判定其不再适用

## 四、实测底数（绮萱 37.6 秒试听）

## 五、缺口

- 第二音色：目前只有绮萱一个神经声库能用（kumi 已判电音、liyuu 不可用），"每首至少 2 种音色"还差一个可用声库
- 特殊气声、特殊尾音这类细节唱法，现在只能靠 bre/voi 参数近似，没有独立音色单元

## 六、大模型给的段落参数（原始版，未采用）

`{"前奏": {"bre": 0, "dyn": 0, "vib_depth": 10, "vib_len": 0}, "主歌": {"bre": 0, "dyn": 0, "vib_depth": 10, "vib_len": 0}, "预副歌": {"bre": 0, "dyn": 10, "vib_depth": 30, "vib_len": 0}, "副歌": {"bre": 0, "dyn": 30, "vib_depth": 40, "vib_len": 0}, "桥段": {"bre": 0, "dyn": 20, "vib_depth": 30, "vib_len": 0}, "尾奏": {"bre": 0, "dyn": 10, "vib_depth": 20, "vib_len": 0}}`

这份数值全 0 的 bre 与 vib_len 会把人声渲成干声（无气声、无颤音），所以生成器里加了安全下限钳制，最终用的是下面第七节的融合参数。

## 七、道自己的音色（融合 5 个唱法模板）

不做真人嗓音克隆，只借唱法特征，配比与目标特征：

- 李健 30%（气声长句、中低声区温暖）· 单依纯 30%（柔和、句尾弱收）· 王菲 15%（轻飘起句）· 那英 10%（副歌实劲）· 童声 15%（绮萱本色基底）
- 融合目标：频谱重心 2228 Hz、气声 0.207、动态 0.596、颤音率 5.57 Hz、音域 11.35 半音
- 落地手段（全在参数层，不用任何音高量化/镶边类效果，所以不会出现电音味）：
  - `bre`（气声）按段落走：主歌 10 → 预副歌 12 → 副歌 12 → 桥段 16（桥段最气，李健式）
  - `voi`（实声度）：前奏 42 → 主歌 72 → 预副歌 84 → 副歌 100（副歌全实声，那英式劲）
  - 颤音周期 150 tick = 5.1 Hz，对齐绮萱实测颤音率，不硬拉成机器颤
  - 后处理链：90 Hz 高通 + 230 Hz 低架 +1.2 dB（胸腔托底）+ 620 Hz −0.8 dB（收童声鼻音）+ 3200 Hz −0.9 dB / 4500 Hz −0.8 dB / 9000 Hz −0.6 dB（去毛刺、收齿音、柔化高频）
